## 离线复算

Python 3.11+，标准库，无需密钥、网络或第三方依赖：

```sh
python tools/reproduce_p0.py
python -m unittest discover -s tests -v
```

前一条命令生成 `research/p0/computed.json`：包含标准化记录、指标、质量状态和图表数据。结果中 `20`/`60` 日窗口及资金金额必须为空并携带原因；没有数据不等于零。

本仓库尚无生产采集器、前端应用、Actions 工作流或部署。不得未经评审自动进入 P1、发布数据、修改仓库可见性或创建付费资源。P0 样例未获公共再分发许可，不能直接进入 Pages 构建产物。
