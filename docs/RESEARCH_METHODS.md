# 研究方法：分维度证据，而非主力资金黑箱分数

方法状态：设计草案，未通过预测有效性验证。P0执行的只有 `raw-nav-change/1` 复算及防错算例，其余公式和状态机是待实现、待验证的规格。

## 1. 决策框架

四个独立维度：资金、价格、广度、风险。先回答数据和证据是否充足，再判断方向。P1不发布综合总分，不使用“上涨概率”“机构吸筹”等超出证据的说法。观察池、窗口、来源日期和覆盖率与每次判断一起保存。

ETF净申赎估算、融资余额变化、大单成交方向估算、互联互通统计绝不相加为“真实总净流入”。它们有不同边界，可能互相重叠；同向不证明来自不同投资者，背离也不必意味着某一方错误。

## 2. 指标规格

设t为交易日，h∈{5,20,60}；所有窗口按版本化交易日历取样。每项结果携带值、单位、窗口、输入日期、质量、覆盖率、方法版本和限制。

### 2.1 ETF份额变化与净申赎估值

S为期末份额；k_t把前一交易日份额换算到当日份额单位，正常无折算时为1。只有权益事件数据确认后才允许取k=1。

`ΔS_i,t = S_i,t − k_i,t × S_i,t−1`

`F_i,t = ΔS_i,t × NAV_i,t`

单位为CNY，NAV为当日单位净值而非收盘价/IOPV。需排除/处理合并、折算、币种变更等特殊事件。计算示例（合成测试，非市场数据）：前100份、1拆2后200份、当日NAV5元，k=2，则流量0；错误忽略k会产生500元假流入。

它是净申赎价值估算，不是精确现金流；实物申赎、套利、同类产品切换、做市库存等都可能造成变化。不能由此识别机构身份，也不能直接断言同额底层股票当天被主动买入。

来源只给今日快照而未提供明确统计日时，指标停用；不能拿前日NAV配今日份额并标为今日实测。P0实样没有S，F全部为空。

### 2.2 渠道资金强度与持续性

窗口起点固定ETF集合U（当时已上市且分类有效），新上市产品另列，清盘/退出保留历史，不以当前存续名单回溯。行业无覆盖时标记缺失。

`F_s,t = Σ_{i∈U_s} F_i,t`

`I_s,h = Σ_{d=t−h+1..t}F_s,d / Σ_{i∈U_s} AUM_i,t−h`

分母为一致范围期初规模，不能用当日膨胀规模掩盖强度，也不在分母缺失/接近零时输出巨大排名。份额变化合计前必须逐产品通过质量门槛。

`P_s,h = count(F_s,d > 0) / h`

真实零计入有效天数但不计正向；缺失日不被默默从分母删掉。h日持续性不应由仅3个非空日生成“100%连续流入”。

参与广度同时报：净申购ETF数量/可观测ETF数量，以及这些ETF的期初AUM/同范围期初AUM。它们是产品广度，不是机构数量。同一指数多产品具有相关性，不能算成多份独立资金证据。

### 2.3 融资维度

`M_s,h = (B_s,t − B_s,t−h) / FloatCap_s,t−h`

B为同口径股票融资余额，FloatCap为明确口径期初流通市值。分别报余额变动金额和比例。标的调入/调出、权益调整、历史分类变更需要对账；证券ETF融资不混入股票行业融资。没有同日融资和ETF数据时，不输出“当日共振”。

上交所说明：融资偿还含直接还款、卖券还款、强平和权益调整；汇总含调出标的残留余额，明细只含当前标的。因此余额变化不完全等于某类投资者净买入，明细与汇总差额需记录和解释。[官方口径](https://www.sse.com.cn/market/othersdata/margin/detail/)

### 2.4 相对强度与量价

目标指标使用同收益口径的行业指数和宽基：`RS_s,h = R_s,h − R_b,h`，单位百分点；价格收益、全收益、ETF净值变化不能混在一个榜中。全收益需要可靠分红/复权方法及当时数据；不能把累计净值简单比值当作分红再投资收益。

P0仅用单位净值变化 `100 × (NAV_t / NAV_(t−h) − 1)`，明确标记未复权；510330是ETF参照，不是官方指数。没有历史事件检查，不把它升级为策略业绩。

成交活跃度建议 `Turnover_t / mean(Turnover_{t−20..t−1})`，单位倍；使用前20完整交易日均值而不含今日。无20日历史则为空。成交量统一股票“股”、ETF“份”；成交额统一元。不能把纯价格上涨造成的成交额放大简单视为净流入。

### 2.5 行业内广度与权重集中

上涨比例：在已核实当日可交易、前收/复权资料完整的成分中，涨幅>0的数量/有效成分数量；平盘进分母，不计上涨。另列停牌数、上市不足数和数据缺失数，并报告对原始行业成分总数的覆盖。

站上MA20/MA60比例按具备对应历史的成分计算；满足历史的子集变化也要显示，避免新股/缺失股被移除后广度虚增。停牌处理固定为“交易广度排除、持仓风险不排除”，在指标名上明确。

权重贡献仅在有前一期有效权重时研究 `w_j,t−1 × r_j,t`；前5贡献与其余贡献分开，并与官方指数变动保留残差（调仓、除数、收益口径等）。无权重时只显示等权广度，不伪造精确指数归因。

### 2.6 风险

20日波动率需要20个有效日收益，年化因子如sqrt(252)应标为建模约定，而非每年一定252个交易日。60日回撤在完整同口径序列上取相对历史峰值的最大跌幅；波动/回撤和资金强度分开，不称作赚钱概率。

同时研究行业权重集中、价格已显著扩张、信号切换频率与潜在交易摩擦。没有足够数据时不以短样本充当20/60日风险。

## 3. 观察状态与条件输出

| 状态 | 必要证据（阈值待回测校准） | 明确不能说什么 |
|---|---|---|
| 资金/价格共同改善 | 相同截至日的资金强度、持续性、RS同时改善，广度不恶化 | 不等于已确认机构建仓或必然上涨 |
| 资金价格背离 | 完整资金流与价格方向相反，检查套利、产品切换与时间错位 | 不自动标记“逆势吸筹” |
| 上涨广度不足 | 行业上涨但等权广度弱/少数权重贡献集中 | 不自动预测马上下跌 |
| 多维转弱 | 资金、价格与广度同口径变弱，风险上升 | 不直接生成清仓命令 |
| 证据不足 | 关键维度缺失、过期、范围不可比 | 不重新配权凑完整评分 |

具体阈值、进入/退出确认天数及滞回参数在独立研究配置中版本化，并预先登记待检验假设，避免看到结果后改规则。P0不填未经检验的固定“胜率最优参数”。

每条观察包含：asof/decision_cutoff、适用周期、事实、直接计算、推论、支持证据、反向证据、缺失证据、触发/失效条件、历史变更记录。证据完整度不是未来上涨概率。

P0示例：芯片产品五间隔净值变动弱于宽基ETF参照；这属于价格偏弱观察。待连续份额与权益事件验证，且同日行业广度可得后再评估是否有资金价格背离。若数据修订/事件导致价格比较不可比，立即撤销该比较，不以已有结论强行解释。

## 4. 研究有效性验证

先做数据审计，再测信息含量，最后才测可执行策略。三者分别验收。

历史样本需覆盖多种市场状态，冻结观察池构建法、窗口、成本和信号阈值。按时间顺序训练/验证/留出测试，采用滚动样本外检验；不能随机打散日序列。不同期限标签重叠时在分割处清除重叠窗口并留适当间隔；显著性使用考虑时间相关的区块重采样等方法，避免把重叠收益当独立样本。

基线至少包含：简单行业动量、ETF净申赎强度、仅价格/广度、资金+价格组合。比较未来5/10/20日相对表现、排序相关性、分组差异、下行风险、误报/漏报、状态切换和不同市场阶段稳定性。训练/阈值搜索的尝试数量一起披露；增量价值不成立则保留更简单方法。

每条前瞻标签在h日后才能生成，最新尚未成熟的标签不当作零收益。分类、成分、上市/退市历史与公告必须使用当时有效且可得版本，禁止当前成分回填历史或修订值穿越。

若评价交易策略，信号形成于收盘后就不能假定当日收盘价成交。先验证具体股票/ETF在对应时点适用的交易规则，再考虑下一可交易时点、竞价、涨跌停、停牌、滑点、费用、流动性和交易限制。研究信号评价与实际可执行回测分开报告。

样本不足时开展前向记录，报告尚无统计结论。本轮没有完成回测，也没有证明这些指标能提高收益。系统用途是组织证据、发现变化、约束冲动决策，而非保证预测。
