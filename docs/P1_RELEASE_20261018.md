## 用户可见交付

本轮交付更新的可交互单文件预览、可独立发布的无数据页面，以及本地导入的私人评审数据包。不是新的市场研究结论。数据仍为仓库已保存的2026-10-08至10-15样例，本轮没有重新抓取或确认源站数值。

- `private/ql-preview.html`：带原历史样例的自用预览，新增数据包入口与上海日期/数据截至日提示。
- `private/ql-review.json`：私人评审数据包；不得放入Pages目录。
- `public/`及`pages-public.zip`：只含8个静态应用文件，无市场数据、持仓、成本或备注。
- `private/ql-shell-offline.html`：与发布界面同逻辑的单文件形式，便于离线评审和受限环境交互测试。不是多文件HTTP导航验收的替代证明。

发布候选分支拟为`pages-ready`，当前文件树仅含`index.html`、`app.js`、`release.js`、`start.js`、`style.css`、`release.css`、`.nojekyll`、`release.manifest.json`。以仓库仅含README的初始化提交为父提交，不继承P0原始样例的提交历史。创建分支不等于创建或发布Pages站点。

## 数据导入及安全边界

用户选择文件后先校验、再确认、最后载入。错误文件保留当前数据。自选备注文件与市场数据包是两种独立格式，不互相接受。

校验包括格式、2MB大小上限、代码/日期重复、有效日期、截止日一致性、来源URL允许范围、有限十进制数、原始序列与指标的一致性。浏览器用BigInt有理数运算按ROUND_HALF_UP对应规则复核净值变化、相对宽基差值、归一化点和条件申赎值，避免二次舍入。测试覆盖负的舍入零和边界。

源站真实性无法由本地JSON证明。该校验只证明受支持格式和算术一致性，不是官方签名、来源认证、权益事件验收、交易日历完整性或预测有效性验证。正式资金金额仍为null，`auto_updated=false`、`public_export_allowed=false`不得由导入文件提升。

这是有意受限的P0预览包版本：只接受原六产品与六观察日结构，20/60日继续缺失。可替换同结构评审快照，但不是通用行情数据库，不是已经接通的日更服务。扩展数据长度、观察池、正式资金、自动抓取和授权公开数据通道需要后续独立变更；不能用本轮导入功能代替这些验收。

导入数据仅在当前标签页的sessionStorage保存，以支持刷新恢复；存储不可用时首次载入可使用内存并明确告知。已有页面替换数据须存储成功后刷新，失败保留旧页面。浏览器标签页复制、崩溃恢复等行为因浏览器而异，不应将标签页关闭描述为安全擦除。自选及已保存备注仍在独立的localStorage键中。导入前提醒保存或导出未保存备注。

本地存储不是访问控制或加密保险箱。同源页面脚本能够读取相关存储；不能把Pages静态站视为私人账户系统。页面无文件上传、追踪器、券商连接或交易执行。

## 构建与发布审计

```bash
python tools/build_release.py
python -m unittest discover -s tests -v
python tools/test_release_browser.py
```

构建在新目录暂存，所有检查通过后原子重命名为新的本地版本；拒绝覆盖旧输出。私人与公共目录分开。公共审计不是只相信manifest中的自述：必须逐文件与源码生成的无数据应用一致，并核对精确文件集合、内容散列，拒绝额外文件和链接。改变私人样例不会改变公共文件内容，已有测试实际修改输入验证。

公开多文件页面只引用同源的脚本和样式，CSP阻止连接型数据请求、嵌入对象和表单提交。只有载入本地数据后才执行应用脚本。单文件私人预览不需要外部应用资产。后续启用同源自动数据更新必须再评审CSP、数据发布许可、版本一致性和失败保留旧版，当前未启用。

## 本轮验收

原67项离线测试先复跑。新增29项，最终96项通过；涵盖JS复算、恶意字段、伪造金额、数据权限标志、缺失、发布目录隔离和防覆盖。浏览器最终40条交互与布局断言通过，最终版本连续两次通过。覆盖公开无数据状态、确认/取消、实际本地文件选择、错误文件保留旧值、标签页恢复逻辑、备注分离、条件金额、历史不足以及6种已载入视口布局。测试中的篡改输入均为明确的合成负例。

浏览器直接HTTP/file导航实测被当前环境策略阻止（ERR_BLOCKED_BY_ADMINISTRATOR）；未修改策略。交互测试将单文件等价HTML注入Chromium，并显式使用内存存储适配器。原生存储持久化、实际刷新、发布多文件资源加载、线上Pages、WebKit/Safari、vivo/iPad实机仍未验收。零外部请求只指该次单文件交互测试，不表示公开多文件站不加载自己的JS/CSS。

测试曾发现异步File.text后立即断言造成偶发失败；已改为等待文件处理完成。没有为了测试放宽CSP。最终截图使用干净页面，避免把测试备注、错误消息和通知留在交付预览中。

## 固定网址仍需完成的外部步骤

本轮实读仓库仍为private、has_pages=false。连接具备代码写权限，但当前工具清单没有Pages管理动作；插件搜索未提供另一个已连接的Pages管理通道。当前工作环境没有已配置GitHub CLI；不得把admin元数据等同于已完成Pages设置。

具备适用账户资格时，可在仓库Settings → Pages选择Deploy from a branch、`pages-ready`、`/(root)`。此动作会启用GitHub的构建/发布机制；账户资格、可用额度及实际发布结果仍需确认。没有自动购买套餐、调用托管runner、改变仓库可见性或部署其他平台。看不到私有仓库Pages选项时不要自动公开仓库。

官方依据：
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- https://docs.github.com/en/rest/pages

当站点发布后，仍须实际核验`/ql/`路径、资产、hash路由刷新、导入、本地存储以及手机/平板，不以候选分支存在替代上线验收。

最终目标仍为打开固定网址后查看自动更新的真实研究数据。本轮本地导入是安全过渡和备用路径，不改变日频自动更新的产品目标。
