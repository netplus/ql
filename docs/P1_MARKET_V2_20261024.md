## 1. 真实验证范围与边界

本地私人预览使用七只 ETF、2026-10-08 至 2026-10-23 的十二个交易日，共84个净值观察值，相比原36个增加48个。新增产品为510050；其余为159995、515030、510330、512010、159819、510030。净值来自基金管理人官方页面的日期表，不是媒体资金流报道。新增样本、可读文本摘录、取证时间和计算结果随私人交付包保存，不提交到公共仓库或 Pages。

三只产品较早的两日净值沿用旧取证，保留旧时刻；510030只沿用原六日份额，10月16日以后没有份额即留空。当前12日历史不能产出20/60日实值指标，未复权净值变化不能称为投资总收益；期间权益事件、行业广度及正式资金指标仍未验收。

当前网页阅读路径可取得新净值；本轮 `collect_nav.py` 对159995、510330的两次实际 HTTP 请求仍在工作容器发生 DNS 解析失败，未归档源站响应或产出HTTP数值记录。不能称为自动采集成功，也不能据此认定源站或未来runner不可用。采集适配器尚需在真实目标运行环境验证；遇到JS页面无日期表必须失败，不绕过访问控制。

仓库本轮读取为 public、has_pages=false；没有站点成功部署证据。本站数据加载能力不等于已接通每日上游采集。

## 2. 新的数据与页面分层

- `config/market-universe.json`：产品元数据、分组、基准与管理人入口；不是正式行业分类。
- `config/calendar-2026-oct.json`：限定日期范围的独立日历，不冒充完整年度交易日历。
- `web/market-data.js`：原始十进制字段校验、旧包迁移、确定性计算、动态视图模型。
- `web/market-app.js`：数量、日期、参照、产品详情、份额覆盖和图表均来自模型。池外自选保留，不因观察池变化自动删除私人记录。
- `web/market-loader.js`：本地导入与同源索引加载；不请求上游交易所，不上传文件。
- `tools/collect_nav.py`：默认dry-run的有限HTTP取证探针和HTML表解析；不是生产调度器。
- `tools/build_market_page.py`：独立生成私人单页预览与公共站点文件，不执行部署。

修正：参照中间日期缺失只影响相对值，不再抹去产品自身有效的窗口变化。净值和份额独立按来源、所属日检查；过期份额不计入当前日覆盖率。缺失不前填，不用零冒充未取得数据。

## 3. ql.market-bundle/2 契约

顶层包含 schema、version、timezone、audience、observed_at、asof、benchmark_code、独立calendar、sources、products。当前只接受 `auto_updated=false`；没有经过持续运行验收就不得改成自动日更。

每个产品含code、exchange、label、name、group、basis、currency及按日期组织的observations。每条记录的 `nav` 单位为人民币元/份，`shares` 单位为份，均用十进制字符串或null；`nav_source`和`shares_source`分别引用来源登记。未取得整日记录也保留日历日期，不压缩窗口。当前只接受CNY与unadjusted_nav口径。

来源包含官方HTTPS网址、提供方、实际取证时刻、可为空的披露时刻、获取方式、响应是否归档及可选证据摘要。网址白名单、摘要和格式校验不证明源站真实性，也不建立历史时点可得性。未知私人字段不进入渲染器。

限制为最多64产品、520个日历观察日、产品数乘日期数不超过16384、原始包不超过2MiB；这是资源预算，不是固定观察池。基准必须存在。用BigInt定点数及有理数计算1/5/20/60日指标，展示时舍入；h日需h+1个完整观察值。每产品条件申赎独立复算，但正式资金金额始终为null。

旧 `ql.review-bundle/1` 可迁移已知六产品评审包：只读取原始字段，重新计算，万份转为份，不信任旧包提供的派生结果。旧数据源码和文件不覆盖。

## 4. 同源更新与公开边界

首次没有已载入数据时，公共页面读取同目录 `market.manifest.json`。有效索引指定 `market.<完整SHA256>.json`、字节数、版本、截至日期；只允许同源相对文件名、JSON MIME、无跳转、无凭据请求，12秒超时，并复核字节数、摘要、用途、日期及版本。

已有数据时不静默替换：新快照需要确认，较旧快照提示历史回看；失败保留现有页面和备注。存储受限显示限制，不宣称已经持久保存。当前没有后台轮询或自动采集调度。

公共构建默认索引为unpublished且不含市场数值；私人预览可内置数据。公开数据须同时满足public-market用途及单独的精确包审核文件：`ql.publication-approval/1`、canonical_data_sha256、完整source_ids和review_reference。该记录是发布审查门槛，不是自动取得数据许可；本次未批准或发布新市场数据。

资产使用内容指纹及SHA384 SRI，CSP仅允许同源脚本、样式和JSON。需要浏览器原生验证真实HTTP加载、完整性拦截和缓存，当前模拟通过不能替代。

## 5. 可复跑命令

```bash
# 仅显示有限请求计划；--execute + 全新--output 才联网
python tools/collect_nav.py --config config/market-universe.json \
  --codes 159995,510330 --start 2026-10-08 --end 2026-10-23

# 原始数据包由私人交付包或后续通过验收的采集流程提供
python tools/build_market_page.py --input /path/to/private-market.json \
  --output /path/to/new-build-directory

node --test tests/test_market_data.js
python -m unittest discover -s tests -p test_nav_ingest.py -v
python tools/test_market_browser.py --preview /path/to/new-build-directory/preview.html \
  --output /path/to/browser-check.json
```

页面使用者不需要Node或Python。构建校验使用Node；浏览器验收工具需要Playwright及Chromium。浏览器脚本明确以本次七产品、十二日的私人实证包为验收输入，不作为任意数据包的通用数据认证。
