## 5. PCF样例：防止错把业务参数当资金量

两只产品的官方PCF提供了可用于字段语义和精度核验的真实数字：

| 字段 | 512010 | 159819 |
|---|---:|---:|
| 清单公告日期 | 2026-10-16 | 2026-10-16 |
| 资产估值所属日期 | 2026-10-15 | 2026-10-15 |
| 最小申赎单位资产净值（元） | 376,860.52 | 2,889,477.68 |
| 次日条款中的最小申赎单位（份） | 1,000,000 | 2,000,000 |
| 当日累计可赎回份额上限（份） | 3,000,000,000 | 800,000,000 |
| 清单单位净值原字段 | 无 | 1.4447 |
| 历史净值表10-15单位净值 | 0.3769 | 1.4447 |

`3,000,000,000`和`800,000,000`是上限，不是总份额、实际赎回份额，更不是净流出。“无”保留为缺失，不能替换成0。PCF现金差额是申赎篮子结算字段，不能当基金整体净流量。

**有条件的算术对账：** 若清单中前日估值与次日最小申赎单位保持相同份额基础，159819的`2,889,477.68 / 2,000,000 = 1.44473884`，四位小数为1.4447；用已舍入NAV反乘得到2,889,400元，77.68元残差可落在四位小数舍入范围内。512010对应0.37686052，反乘残差-39.48元。

这只验证条件算术的一致性，不证明该最小单位在跨日没有调整；`creation_unit_continuity_verified=false`。更不能将残差理解为市场资金流。

本次清单在10月16日读取，不能作为系统10月15日收盘时已经知道的信息。即便字段所属日为10月15日，历史决策重建仍须通过`first_seen_at/decision_cutoff`约束；未知原始发布时间不补写。

## 6. 指标与研究方法放行标准

采用资金、价格、广度、风险四维，不先构造不透明综合分。以下是拟建规格，不宣称已验证预测能力。

**资金：** `ΔS_i,t = S_i,t − k_i,t S_i,t−1`，`F_i,t = ΔS_i,t NAV_i,t`。k把前日份额换算为当日份额基础，不能未经事件核查默认1。只有日期相邻、同日NAV、单位明确、份额和事件核验均通过才计算。F是净申赎价值估算，不能识别投资者或断言同额股票二级市场净买入。

行业渠道强度`I_s,h = Σ F_s,d / AUM_s,t−h`，持久性`P_s,h = 正流量天数/h`。窗口集合固定并版本化，新上市另列、退市不删除历史；真零计入有效天数，缺日不从分母偷偷去除。报告金额、相对规模和产品参与广度，避免大产品因规模自动排名靠前。同指数ETF不是多份独立机构证据。

**融资：** 同范围融资余额变化金额及其占期初流通市值比例。上交所说明偿还额还含权益调整；当前标的明细与汇总范围不同，所以不能强行断言两者总和必相等。股票行业融资与ETF融资分开；不同日数据不称同日共振。

**价格与广度：** 同收益口径的行业/宽基RS，今日成交额/此前20日均额，上涨比例、站上MA20/MA60比例及前一期已知权重贡献。没有历史权重只给等权广度，不冒充精确指数归因；停牌、新股、缺失各列数量与规模覆盖。

**风险：** 完整窗口波动、回撤、集中度、信号切换频率、执行摩擦。波动年化系数是研究约定，不伪装成每年固定交易日数。

小观察池采用必需字段100%齐全才允许资金横向比较；扩展门槛必须另行预注册。总体份额或映射分母未知时，规模覆盖率也未知，不能显示“全市场100%覆盖”。单产品或整维缺失时不重配权凑出总分。

状态用“资金/价格共同改善”“资金价格背离待确认”“上涨广度不足”“多维转弱”“证据不足”。每次输出保存支持/反对/缺失证据、适用周期、触发/失效条件与历史版本。数据完整度不等于上涨概率。

研究先审计数据，再检验增量信息，最后才讨论可交易策略。使用滚动时间划分、重叠前瞻窗口隔离、考虑时间相关的统计不确定性，比较简单动量、单一资金、价格/广度基线。报告全部参数试验与样本外失败；没有历史就前向记录。收盘后形成的信号不假设当日收盘成交。P0未开展回测。
