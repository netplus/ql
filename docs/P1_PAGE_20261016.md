## 页面与功能

| 入口 | 当前实现 |
|---|---|
| 观察概览 | 样例日期、覆盖、六条净值曲线、分类搜索排序、产品自选 |
| 方向比较 | 实际日净值变化热力表，点击日期单元格进入产品详情 |
| 产品详情 | 选择产品、净值、份额曲线、条件申赎、原始字段与来源弹窗 |
| 自选复盘 | 本地星标、当前备注、导入导出、清空确认；尚无历史修订日志 |
| 数据方法 | 来源、取证时间、公式、缺口、版本和公开发布限制 |

PC使用侧栏与表格；手机使用底部导航与产品卡片；平板按CSS视口重排。
图表可以点击或通过键盘查看日期读数，不依赖hover。热力表在自身区域横滑。
无第三方脚本、字体、图片、CDN或分析服务；CSP禁止网络数据请求。

## 数据与计算

本轮读取原仓库的NAV和份额样例，与挂载副本Git blob SHA逐项一致后构建。
六只ETF：159995、515030、510330、512010、159819、510030，共36个NAV值；
仅510030有6个总份额值。实际数据日期为2026-10-08至2026-10-15。
不是六行业，也不是全A股覆盖；没有在本轮重新取得源站数据。

净值变化、相对变化及条件金额在Python Decimal层预计算；日期/窗口结果一并导出。
显示百分比由未舍入值直接舍入到两位，避免六位再两位的二次舍入。
JS仅筛选和绘制这些值；绘图坐标转换不承担信号计算。

基准为510330的未复权NAV，不是官方指数。20/60日以及过早截止日的5日指标为空。
510030五日条件金额为-710.15万元，当日为-109.20万元；事件未核验，正式金额仍为null。
条件金额默认收起，展开时先显示未验证前提。缺失NAV、份额和历史均不前填。

WebKit/Safari、vivo/iPad实机。视口测试不能替代这些验收。
