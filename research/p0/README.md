# P0 样例证据与复算

`nav_sample.json` 是官方网页文本中的 18 条净值原始字段摘录。它不是自动 HTTP 抓取响应，也不是可证明历史披露时刻的归档。精确来源 URL、网页证据位置、记录时刻、市场时区和禁止公共导出的状态均在文件中。

`original_rows` 的“日期/净值/累计净值”保留源字段。代码仅为产品关联键。六个日期形成五个交易间隔；没有完整20/60日历史。没有每日份额、期初AUM、融资明细、行业广度或当时已知的历史分类，因此相关结论缺失，不以零代替。

运行：

```sh
python tools/reproduce_p0.py
python -m unittest discover -s tests -v
```

`computed.json` 含标准化数据、1/5/20/60窗口状态、宽基ETF参照差值、净申赎金额不可用状态、逐日归一化图表数据以及输入文件SHA-256。相同输入和方法得到相同结果。SHA-256只是本地输入的校验值，不是源站原始响应的哈希。

## 图表定义

图表使用 `chart[].rebased_nav[code]`，横轴 `trade_date`，纵轴 `NAV_t / NAV_2026-10-08 × 100`。三条线同尺度，标题须写明“未复权单位净值”，图注须写明“不是资金流、市场价格或已验证全收益”。不能将这些线画成行业资金迁移图。

所有计算为未复权数值变化。累计净值保留但不用于计算，不假定分红再投资口径；权益事件检查未完成。不能用于证明历史交易策略可获利，也不能作为10月15日收盘时已经掌握的信息。
